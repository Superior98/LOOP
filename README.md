# 🔴 LOOP

## 📌 Assessment Website

Welcome to **LOOP**, my website created for this competency task.

This repository contains all the files required to run the website locally.

## 💾 Download Instructions

1. Download the website files here: [Download LOOP Website](https://github.com/Superior98/LOOP/archive/refs/heads/main.zip)
2. Extract the downloaded ZIP file.
3. Delete the compressed ZIP file after extraction.
4. Open the extracted folder.
5. Open **`index.html`** to launch the website.

## 🌐 Running the Website

No installation is required. Simply open `index.html` in a web browser to view the website.
